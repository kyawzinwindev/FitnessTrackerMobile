# FitnessTrackerMobile

FitnessTrackerMobile is a native Android application built with Kotlin designed to help users log workouts, track daily physical activity, monitor fitness goals, and view health metrics through a modern mobile interface.

---

## Features

### For Users
- **Activity Tracking:** Log daily workouts, exercises, durations, and estimated calories burned.
- **Goal Management:** Set and track personal fitness milestones such as daily step targets or weight goals.
- **Workout Logs:** View comprehensive exercise history and progress summaries over time.
- **Intuitive UI:** Designed with modern Android UI principles for fluid navigation and readability during workouts.

---

## Tech Stack

- **Language:** Kotlin
- **Platform:** Android SDK
- **Architecture:** MVVM (Model-View-ViewModel)
- **UI Framework:** Jetpack Compose / XML Layouts
- **Database / Storage:** Room Database / Shared Preferences

---

## Prerequisites

- **Android Studio:** Jellyfish or newer recommended
- **JDK:** Version 17 or higher
- **Android SDK:** API Level 24 (Android 7.0) or higher

---

## Installation & Setup

Follow these steps to set up and run the application locally.

### 1. Repository Setup
Clone the repository to your local machine:

git clone https://github.com/kyawzinwindev/FitnessTrackerMobile.git
cd FitnessTrackerMobile

### 2. Open Project in Android Studio
1. Launch Android Studio.
2. Select **Open** and navigate to the cloned `FitnessTrackerMobile` directory.
3. Allow Gradle to sync and download all necessary project dependencies.

### 3. Build & Run
1. Connect a physical Android device via USB (with Developer Options & USB Debugging enabled) or set up an Android Virtual Device (AVD).
2. Select your device/emulator in Android Studio.
3. Click the **Run App** button (or press Shift + F10) to build and install the APK.
